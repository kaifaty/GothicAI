# Gothic AI на Linux

**Предварительная сборка.** Готовый архив собран на GitHub из этого репозитория и прошёл там автоматические проверки. Компилятор и исходники не нужны. Игра, графика, звук, микрофон и голоса на настоящем компьютере с Linux ещё не проверялись: если что-то не работает, смотрите раздел «Если что-то не так».

## Что нужно

- 64-битный Linux на процессоре x86-64 с glibc 2.35 или новее: Ubuntu 22.04 и новее, Debian 12 и новее, Fedora 36 и новее, SteamOS 3 и похожие. Версию glibc показывает `ldd --version`.
- Драйвер видеокарты с поддержкой Vulkan (`libvulkan.so.1`): Mesa для AMD и Intel или драйвер NVIDIA.
- Русская Gothic II Gold (с «Ночью Ворона»), купленная и установленная через Steam. Подходит и установка через Proton: Gothic AI нужны только файлы игры, сама Gothic II не запускается.
- Подписка ChatGPT и ключ API Inworld: им распознаётся речь игрока и озвучиваются NPC.
- Интернет: при первой настройке скачиваются Python и библиотеки, в игре — ответы и голоса NPC.
- Микрофон и библиотека PortAudio для него: `sudo apt install libportaudio2` (Ubuntu, Debian), `sudo dnf install portaudio` (Fedora), `sudo pacman -S portaudio` (Arch). Без неё игра идёт, но NPC вас не слышат.

## Первый раз

1. Скачайте из Releases архив `GothicAI-linux-x64-….tar.gz` и файл `SHA256SUMS`. Проверьте архив: `sha256sum --check --ignore-missing SHA256SUMS` должен ответить `OK`.
2. Распакуйте архив целиком в папку без пробелов, например `tar -xzf GothicAI-linux-x64-….tar.gz -C ~` — появится папка `~/GothicAI-linux-x64-…`.
3. В терминале перейдите в эту папку и запустите `./Setup-GothicAI.sh`. Он проверит драйвер Vulkan и PortAudio, подготовит ИИ-сервисы, найдёт игру в Steam (обычном или Flatpak, в том числе во второй библиотеке Steam) или попросит вставить путь к её папке. Потом попросит вставить ключ Inworld (символы при вводе не видны) и откроет браузер для входа в ChatGPT. Первая настройка скачивает несколько сотен мегабайт.
4. Когда появится «Готово», терминал можно закрыть.

Права администратора Gothic AI не нужны: он ничего не ставит в систему. Если нет драйвера Vulkan или PortAudio, `Setup-GothicAI.sh` покажет команду для вашего дистрибутива.

## Игра

- Запускайте `./Start-GothicAI.sh` из папки Gothic AI. Терминал не закрывайте, пока играете: в нём работают ИИ-сервисы. Закроете игру — всё остановится само. `./Start-GothicAI.sh --new` начинает новую игру.
- Чтобы заговорить с NPC, удерживайте **T** и говорите, потом отпустите.
- Первый запуск дольше обычного: до старта игры Gothic AI несколько минут готовит её данные и ролики из файлов Gothic II, прогресс виден в терминале. Готовые данные занимают несколько гигабайт в `~/.cache/gothic-ai/base`, следующие запуски берут их сразу.
- После настройки браузер для игры не нужен.

## Если что-то не так

- `Setup-GothicAI.sh` пишет, что не найден `libvulkan.so.1`, или игра не открывает окно: поставьте драйвер Vulkan вашей видеокарты из своего дистрибутива. Проверить драйвер можно командой `vulkaninfo --summary` (пакет `vulkan-tools`).
- Игра пишет про `GLIBC_2.3x`: дистрибутив старше нужного, glibc нужен 2.35 или новее.
- NPC не слышат вас: поставьте PortAudio (команды выше) и проверьте, что микрофон выбран устройством ввода по умолчанию в настройках звука.
- Если в Gothic II стоят моды (лишние архивы `.vdf` в папке `Data`), укажите копию игры без них: `./Setup-GothicAI.sh --game-dir "путь к Gothic II"`. Отдельной команды для профиля без модов на Linux пока нет.
- Чтобы сменить ключ Inworld, выполните `./Setup-GothicAI.sh --change-key`.
- Логи каждого запуска — в `~/.local/state/gothic-ai/logs`. Опишите проблему в issue и приложите вывод терминала и логи последнего запуска: https://github.com/kaifaty/GothicAI/issues.
