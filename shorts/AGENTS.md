# shorts/ — шортсы из игры

Как снимать, монтировать и загружать — [`README.md`](README.md); навыки `showcase` и `explainer` ведут работу целиком. Общие правила — корневой [`AGENTS.md`](../AGENTS.md).

- **После правки:** `python3 scripts/check.py run` из корня — тесты, которые отвечают за изменённые файлы. Игру для тестов не запускай. В CI тесты shorts идут на macOS (arm64): проверки сведения на amd64 дают другие числа.
- **Загрузка на YouTube — только с явного согласия пользователя**, каждый раз: файл, заголовок, субтитры, приватность.
- **Русский голос за кадром записывает пользователь** (`gothic-shorts studio`). Не подставляй TTS или клон голоса.
- **Звук дубля:** `film` пишет `musicVolume=0` и `worldSounds=0`, музыку монтаж кладёт одной подложкой. Старые дубли без звука NPC отдельно и без этих настроек снимают заново.
- **Готовый ролик выпускает только `levels.publish`:** −14 LUFS, голос громче эффектов, эффекты громче музыки, проверка AAC на щелчки и пики. Не прошла проверка — MP4 нет.
- **Финальная съёмка — на Mac.** Бенч на Ryzen (`scripts/bench.sh` идёт туда по умолчанию) пишет без звука и годится только для разведки места.
- **Перед съёмкой** проверь `pgrep -fl Gothic2Notr`: на Mac — одна игра за раз.
- Заметки о канале и аудитории в репозиторий не кладутся: он публичный.
