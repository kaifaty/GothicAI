# Журнал решений: {title}

Ассет `{asset}`. Сюда пишутся решения пользователя на воротах (дословно) и отказы с причинами, по одной записи. Записи добавляет `remaster.py decide`; руками не правятся. Каждый отказ также дописывается в [список отклонённых дефолтов](../../../../docs/remaster-defaults.md).
