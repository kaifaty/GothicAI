# Деревья по цене: план

Статус: план, 2026-11-18. Пользователь 2026-11-18 решил записать шесть мер удешевления деревьев в план и вести их шаг за шагом; задачи ставит ведущая сессия Claude, исполняет Codex (`gpt-6.2-sol`, `ultra`).

Рамки:
- вид ели А и её движение на ветру приняты пользователем (2026-11-17, 2026-11-18): шаги плана их не меняют, кроме шага 5, который идёт только с согласия пользователя;
- вид каждого шага, который виден глазу, принимает пользователь по клипу; кадры и клипы до него смотрит ведущий;
- замеры — по бюджету ([`AGENTS.md`](../AGENTS.md), раздел «Тесты»): задача с кодом цену сама не мерит, цену партии шагов снимает один общий прогон;
- основание — [исследование способов](../reports/engine/2026-11-16-modern-trees/tree-optimization.md) и [проба цены](../reports/engine/2026-11-16-modern-trees/tree-cost.md).

### Цель

Ограждение из пробы цены для леса около 1 000 елей — до 4 мс видеокарты сверх контроля, из них `GBuffer` ≤ 2,5 мс, тени ≤ 1 мс, GI и заслоны ≤ 0,5 мс. Основной проход — не больше ~10 млн треугольников на лес. По замеру шага 3 кадр укладывается в +4 мс с 300 м и у границы со 100 м (+3,97 мс).

### Плотный лес при 720p — солнечные тени и скрытые ветви

**План от 22 ноября 2026 года.** Цель игры — 8 мс на полный кадр. В исходном замере леса из 1 024 елей на RTX 3080 при 1280×720 → 2560×1440 получилось 14,04 мс в среднем и 14,84 мс по P95. Среднее GPU — 13,98 мс, в том числе 5,04 мс на `VSM-rendering` и 3,32 мс на `GBuffer`. Для главного вида выбирается 4,44 млн треугольников хвои за кадр. До 8 мс по P95 в этом ракурсе остаётся 6,84 мс. На момент составления плана замера на ходу при таком разрешении ещё не было. Ниже приведены результаты для смешанной посадки. Исходные числа — `tree-budget-sparse-cost/budget-8ms-20261122/matrix.csv` на хранилище, строка `original-taau/view-1`, сборка `916656950`.

**1. Измерить, какую работу можно пропустить.** В архивных 569 кадрах изнутри леса на два самых грубых солнечных уровня m7–m8 приходится 38 719 из 331 143 пар «мешлет — запись карты» за кадр (11,7 %), на два самых подробных m0–m1 — 94 360 (28,5 %). Это число подач геометрии. В журнале нет устойчивого идентификатора содержимого каждой страницы. Сейчас таблица и атлас строятся заново, камера сдвигает проекцию, а солнце поворачивается с игровым временем. [Путь страницы по движку](../reports/engine/2026-11-16-modern-trees/tree-shadow-cost.md#солнце-перерисовывается-каждый-кадр)

- В одном диагностическом запуске оставить обычную отрисовку. Сначала сопоставить матрицы солнца в соседних кадрах. Точный повтор возможен, пока лучи и глубина совпадают на сетке данного мипа. Если уже здесь верхняя граница на проходе мала, разработку кэша остановить. Для оставшихся плиток сопоставить мировую ячейку в проекции света, старое и новое покрытие заслонок, ветер, ступень геометрии, диапазон глубины приёмников и соседей фильтра. Отдельно посчитать совпадения адреса, доказанно пригодную глубину и причины сброса. Взвесить результат парами и треугольниками. Для объединённого прямоугольника засчитывать пропуск всей отрисовки только при пригодности всей записи.
- Для запасного варианта теней посчитать пары m0–m1, которые тест глубины приёмников позволил бы пропустить. Для главного вида посчитать выбранные узлы и треугольники кроны целиком вне обзора, затем отдельно те, что закрывает уже построенная глубина. Различать обычный полный меш и компактный срез. Для решения использовать результат прохода героя с ветром и идущими часами наравне со стоячим видом.

**2. Выбрать один пилот для солнечных теней.** Предлагаемый порог для прототипа кэша — не менее четверти подаваемых солнечных пар на маршруте пригодны для точного переиспользования. Это порог отбора идеи. Экономию в миллисекундах определит замер.

- При достаточной доле взять один мип с наибольшим объёмом пригодной работы. Сохранить глубину в ограниченном пуле плиток. Повторное использование разрешить при том же положении световых лучей и достаточном покрытии глубин. При промахе или вытеснении страницу очистить и нарисовать в этом кадре. Движение, появление и удаление заслонки помечают и старое, и новое покрытие. Учитывать живой ветер рядом с героем, смену теневого LOD и веса перехода. При смене сетки света, мира или пересоздании атласа сбросить несовместимые плитки. Брать изменения из штатных обновлений объектов. Измерить память, копирование, время отбора и пики перерисовки. Кэш ламп прежде добавил около 1,6 мс на Ryzen из-за сбора изменений на CPU. - Если тень пригодна в основном при остановленных часах или только на стоячей камере, перейти к отсечению по глубине приёмников на m0–m1. Для мешлета с запасом на ветер пропускать пару, только если он целиком за всеми затронутыми приёмниками. Применить одинаковый критерий при подсчёте и записи пар. При неполном покрытии глубины, на границе фильтра и для запросов тумана оставить обычную подачу. [Существующий тест на уровне кластера и проект для мешлета](../reports/engine/2026-11-16-modern-trees/tree-shadow-cost.md#точный-отбор-мешлета-по-глубине-приёмников)

**3. Отсечь ветви до записи команды главного вида.** Запечённая коробка узла охватывает исходные и упрощённые карточки с запасом для ветра. Проверить её при фактической силе ветра материала и преобразовании экземпляра. Начать с теста границ обзора у уже выбранного узла перед записью в `boughEmit`. Если диагностика показала существенный остаток скрытой геометрии, передать в обход уже построенную пирамиду глубины текущего кадра (HiZ). Для крупных групп проверить ближайшую глубину коробки по всем пересечённым ячейкам. При неопределённой границе, пересечении ближней плоскости или недостоверной глубине группу рисовать. При скачке камеры использовать штатный сброс истории. Сохранить веса обеих сторон перехода LOD и быстрый путь полного меша. Скрытая от камеры ветвь по-прежнему может отбрасывать видимую тень, поэтому новый отсев действует только в главном виде. Отдельный предпроход хвои уже добавлял 3,40 мс изнутри леса. [Запас на ветер](../scripts/content/mesh3d/blender/fir_hierarchy.py) · [Запись геометрии ветви](../OpenGothic/shader/materials/tree_bough_expand.comp) · [Порядок работы с HiZ](../OpenGothic/common/graphics/renderer_hiz_history.cpp) · [Изолированные пробы](../reports/engine/2026-11-16-modern-trees/tree-bough-lod.md#дешёвая-отрисовка-среза)
