## Как работает сейчас

Материал дерева объявляется полем `"foliage": {"anchor": "tree"}`; меш — свой GLB с `COLOR_0`.

| Что | Состояние | Документ |
|---|---|---|
| Ветер: ствол, ветки по длине, хвоя; порыв идёт по кроне | принят пользователем | [`tree-wind.md`](../reports/engine/2026-11-16-modern-trees/tree-wind.md) |
| Затухание ветра с расстоянием: хвоя, лапы, ствол | включено, `OPENGOTHIC_TREE_WIND_FADE=0` выключает | там же, раздел 4 |
| Двусторонние материалы | включено | [`two-sided.md`](../reports/engine/2026-11-16-modern-trees/two-sided.md) |
| Свет кроны по открытости из вершины | принят пользователем | [`crown-light.md`](../reports/engine/2026-11-16-modern-trees/crown-light.md) |
| Кроны не служат заслоном в `HiZ` | включено, `OPENGOTHIC_HIZ_SKIP_CROWNS=0` выключает | [`hiz-occluders.md`](../reports/engine/2026-11-16-modern-trees/hiz-occluders.md) |
| Уровни детализации: до четырёх грубых сеток полем `levels`, жёсткая смена по высоте на экране, лучи видят самый грубый уровень | включено, `OPENGOTHIC_MESH_LEVELS=0` выключает | [`tree-lod.md`](../reports/engine/2026-11-16-modern-trees/tree-lod.md) |
| Импостер своего статического меша: запечённые виды в последней ступени `levels`, штатное освещение через G-буфер, последний GLB для лучей и резервной тени | включён, `OPENGOTHIC_IMPOSTORS=0` или `[INTERNAL] impostors=0` выключает | [`tree-impostor.md`](../reports/engine/2026-11-16-modern-trees/tree-impostor.md) |
| Тени дерева переходят с GLB картинки на свой грубый уровень ниже 800 px в пересчёте на 1080p и возвращаются к GLB картинки от 880 px. Солнце и лампы используют одну ступень. VSM берёт мешлеты, чьи сферы задевают запись страницы | включено, `OPENGOTHIC_SHADOW_LEVELS=0` или `[INTERNAL] shadowLevels=0` возвращает GLB картинки | [`tree-shadow-level.md`](../reports/engine/2026-11-16-modern-trees/tree-shadow-level.md) |

Чего нет: отсечения картинки по размеру и по частям дерева, коллизии по материалу. Тень солнца над большим лесом ещё моргает на дальнем плане — починка идёт отдельной задачей.

### Цель

Ограждение из пробы цены: лес около 1 000 елей в кадре стоит не дороже 4 мс видеокарты сверх контроля, из них `GBuffer` ≤ 2,5 мс, тени ≤ 1 мс, GI и заслоны ≤ 0,5 мс; треугольников основного прохода — не больше ~10 млн на лес. Сейчас лес стоит 6,7–15 мс сверх контроля.
