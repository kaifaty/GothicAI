# Трава по цене: план

Шаги 1–5 выполнены к 2026-11-19. Пользователь 2026-11-18 решил вести оставшиеся меры удешевления луга по плану. Задачи ставит ведущая сессия Claude, исполняет Codex (`gpt-6.2-sol`, `ultra`).

Рамки:
- вид луга и дороги принят пользователем (луг — 2026-11-15, дорога как приближение — 2026-11-17). Шаги 1а, 2 и 3 сохраняют вид. Вариант числа звеньев на шаге 4 принимает пользователь по кадрам и клипу. До него кадры смотрит ведущий; исполнитель снимает и возвращает пути, оценку вида не даёт;
- по виду — один круг правок ([`AGENTS.md`](../AGENTS.md), «Новое — сначала исследование»);
- замеры — по бюджету ([`AGENTS.md`](../AGENTS.md), раздел «Тесты»): задача с кодом цену сама не мерит, кроме счёта, без которого не принять решение внутри задачи; цену партии снимает один общий прогон (шаг 5). Поэтому у каждой меры есть выключатель;
- основание — [замер и исследование цены луга](../reports/engine/2026-11-17-grass-cost/README.md), долг [#1480](https://github.com/kaifaty/GothicAI/issues/1480).

### Числа на 2026-11-19

Ryzen, RTX 3080, 2560×1440, трассировка, `main` на `2ff325db3`, контент `working-34`. [Общий замер](../reports/engine/2026-11-17-grass-cost/README.md#шаг-5-общий-замер).

- Весь луг против игры без травы стоит +0,706…1,383 мс видеокарты по двум парам. Средние по видам — +0,776…1,275 мс. Ограждение 1,5 мс выполнено во всех 10 сравнениях.
- По средним разницам A − C проход `GBuffer` добавил +0,011…0,393 мс, `Grass` — +0,384…0,557 мс, `DirectSunLight-VSM` — +0,035…0,138 мс.
- После меры 1 на `working-34` материал колеи добавляет 0,15 мс на виде 5 и 0,04 мс на виде 1. Отдельные части ниже порога разбивки 0,05 мс. [Замер](../reports/engine/2026-11-17-grass-cost/README.md#шаг-3-колея).
- В замере квадратов 2 м до экрана не дошли 25–43 % поданных травинок. По расстоянию ушли в землю 11–28 %, вне обзора остались 14–18 %. [Замер квадратов](../reports/engine/2026-11-17-grass-cost/README.md#мера-2-квадраты-2-м).

### Цель

Ограждение #1480: луг стоит не дороже 1,5 мс видеокарты сверх игры без травы на всех пяти видах `perf-meadow.bench`, включая вид стоя на колее.
