# Трава по цене: план

Статус: план, 2026-11-18. Пользователь 2026-11-18 решил вести оставшиеся меры удешевления луга по плану; задачи ставит ведущая сессия Claude, исполняет Codex (`gpt-6.2-sol`, `ultra`).

Рамки:
- вид луга и дороги принят пользователем (луг — 2026-11-15, дорога как приближение — 2026-11-17). Шаги 1а, 2 и 3 сохраняют вид. Вариант числа звеньев на шаге 4 принимает пользователь по кадрам и клипу. До него кадры смотрит ведущий; исполнитель снимает и возвращает пути, оценку вида не даёт;
- по виду — один круг правок ([`AGENTS.md`](../AGENTS.md), «Новое — сначала исследование»);
- замеры — по бюджету ([`AGENTS.md`](../AGENTS.md), раздел «Тесты»): задача с кодом цену сама не мерит, кроме счёта, без которого не принять решение внутри задачи; цену партии снимает один общий прогон (шаг 5). Поэтому у каждой меры есть выключатель;
- основание — [замер и исследование цены луга](../reports/engine/2026-11-17-grass-cost/README.md), долг [#1480](https://github.com/kaifaty/GothicAI/issues/1480).

### Числа на 2026-11-18

Ryzen, RTX 3080, 2560×1440, трассировка, контент `working-29`.

- Весь луг против игры без травы до обеих мер — +1,5…1,8 мс видеокарты; после них не мерен. По разнице строк — около 1,0–1,4 мс.
- Строка `Grass` — 0,56–0,62 мс (было 0,73–0,94). Подача — 70–85 % строки, растеризация и пиксели — 0,11–0,30 мс.
- Солнечный луч травы — +0,12…0,33 мс в проходе `DirectSunLight-VSM`. До меры 1 колея добавляла 0,4…0,5 мс на виде 5. После меры 1 на `working-34` её материал добавляет 0,16 мс на виде 5 и 0,04 мс на виде 1. Отдельные части ниже порога разбивки 0,05 мс. [Замер](../reports/engine/2026-11-17-grass-cost/README.md#шаг-3-колея)
- Из поданных травинок до экрана не доходят 25–43 %: 11–28 % ушли в землю по своему расстоянию, 14–18 % вне обзора — это запас правил, а не ошибка.

### Цель

Ограждение #1480: луг стоит не дороже 1,5 мс видеокарты сверх игры без травы на всех пяти видах `perf-meadow.bench`, включая вид стоя на колее.
