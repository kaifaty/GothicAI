# Свой контент: рабочий набор и конвейер ремастера

Подключение рабочего контента, исходная база, учёт ресурсов и порядок ремастера. Сводка — в разделе [«Как работает сейчас»](own-content.md#как-работает-сейчас).

## Рабочий контент и исходная база

- **Рабочий контент** с 2026-10-22 (решение пользователя) лежит на Mac в `~/.local/share/gothic-ai/content`, набор `working-4`:
  - кровли `roofs-8`;
  - дерево города `timber-7` (резьба доски конюшни восьмёрками);
  - стены, окно и фронтон хижин порта и балка ферм `hut-10`;
  - бочка порта с износом по модели.

  Игра и лаунчер берут его без `OPENGOTHIC_CONTENT`. Набор собирает `building_set.py compose`, ставит `building_set.py enable`, состав записан в `enabled.json`. Выключить можно двумя способами: `OPENGOTHIC_CONTENT=` или убрать из каталога `materials/` и `meshes/`. На Ryzen каталог по умолчанию не заполняется: его читают бенчи и e2e. Личная установка получает тот же набор в `~/.local/share/gothic-ai/play-content` при `scripts/ryzen-play.sh install|update`, лаунчер передаёт его игре через `OPENGOTHIC_CONTENT`.
- Базовое содержимое игры — оригинальное: мир, наборы объектов, камеры, свет, статичные меши и текстуры читаются из обязательной базы, импортированной из `.VDF` и `_work`; персонажи, анимации, звук и скрипты — по-прежнему из архивов через ZenKit ([П8б](asset-migration.md#как-работает-сейчас)). Свои материалы и меши подключаются отдельными индексами каталога контента, описанными ниже. Логика, диалоги и предметы — скрипты Daedalus из `GOTHIC.DAT` и других `.DAT`.
- HD-текстуры персонажей (`scripts/hd-textures.sh`, `OPENGOTHIC_TEXTURES`) подменяют текстуры по имени, но сделаны апскейлом оригиналов, то есть производные. Это переходный путь: в своей игре его не будет.
- Оригинальные голоса актёров клонируем только для игры (решение пользователя 2026-10-27); шортсы остаются на придуманных голосах ([текущее поведение TTS](MVP.md#как-работает-сейчас)). Ванильные реплики скриптов звучат оригинальной озвучкой.

## Учёт и ограничения

- Перепись сессии: `OPENGOTHIC_CENSUS=<путь к json>` записывает открытые оригинальные файлы по видам, источникам и числу открытий, отдельно HD-подмены; JSON сохраняется при выходе и Marvin `census`, сводка — `python3 scripts/content-census.py <json...>`; для Ryzen задайте абсолютный путь внутри каталога вывода `BENCH_HOST=ryzen scripts/bench.sh smoke <out>` (без переменной учёт выключен).

Ограничения сейчас: без установленной Gothic 2 игра не запускается.

### Конвейер ремастера

С 2026-10-21 постройки и наборы предметов переделываются по [конвейеру ремастера](remaster-pipeline.md), скилл `remaster`:
- лист замысла оригинала с атомарным списком сохранения;
- концепция и концепт, текстуры как правки концепта;
- `building_set.py`: цвет по материалам, набор поверх базового;
- пары «оригинал | наше» в игре;
- рецензент `remaster-reviewer` в чистом контексте, слепой и в двух порядках;
- решения пользователя на воротах.

Ассеты лежат в `reports/content/remaster/<ассет>/`, их исходники `image_gen` — с C2PA и копией на dev-ubuntu. Первые ассеты:
- дом у рынка — эталон калибровки;
- хижина порта — набор `hut-1`.

С 2026-10-21 по решению пользователя всё сделанное раньше — `city-1`…`city-4`, пилоты, `house-2`, предметы рынка — переделывается по конвейеру. Порядок и раскладка 78 текстур по ассетам — в [очереди переделки](remaster-pipeline.md#очередь-переделки). Новые наборы собираются на базе оригинала и соединяются командой `building_set.py compose`.

[Отклонённые дефолты](remaster-defaults.md) пополняются после каждого отказа.

### Дом у рынка: концепция и текстуры

[Принятая концепция и текстуры](../reports/content/2026-10-market-house-concept/README.md#текстуры-дома) начинают со здания и фасада по его геометрии. Шесть альбедо получены правками принятого концепта в одном треде. `scripts/content/market_house.py prepare/build` берёт выбранные попытки из `content-sources/market-house-selection.json`: один Lanczos в 1024², узкие стыки 1/64 по U/V (у WINDOW_03 только U), затем один общий набор линейных RGB-усилений. Его цель — среднее шести `target_oklab`, переведённых в линейный RGB и взвешенных площадями треугольников этого дома из `market-house-measurement.json`. Максимальная ошибка канала после квантования — 0,0000278; индивидуальная яркость ±25% только отмечается: за пределом три каменных модуля и балка. Подгонки детали, Marigold и плеча нет, детектор света только записывается; normal/ORM получаются прежним CPU-фильтром из итогового альбедо.

Реестр `data/content/market-house.jsonl` хранит по шесть рецептов house-1 / house-2 и все девять попыток с промптами, моделью и SHA. Карты — `content-staging/market-house-sources/`, отдельный набор — `content-staging/house-1/`: 58 записей, 12 целевых замен (шесть дома и шесть прочих пилотных). Относительно `pilot-3b` изменены шесть записей; остальные 52 записи и 156 DDS сохранены побайтно. Выключение — не подключать `house-1`; рабочий content и прежние наборы сохраняются. Съёмка `QUALITY_PILOT_TASK=gothic-ai/market-house` использует одну сборку, тот же сейв, полдень и три камеры `market-house.bench`: весь передний фасад с земли, бок с каменным низом и прежнюю `facade`. `--compose-house` собирает original / iteration 3b / house-1 с панелями 768×432. Проверки — `pytest scripts/content/`, таблица, реестр с исходниками и игровая перепись всех 12 целей; границы яркости и флаги света видны в отчёте и требуют визуальной приёмки.

Три игры original / pilot-3b / house-1 завершились с exit 0, сняты 9/9 кадров. У house-1 проверены 12/12 замен и 0 открытых целевых оригиналов, у original — 12/12 открытий. Отчёт содержит три JPEG-сравнения и лист альбедо 369 КБ; тесты контентных скриптов — 814 passed, таблица — 78 строк, реестр — 6 рецептов / 9 PNG. Резервная копия исходников на dev-ubuntu совпала в 18/18 файлах.

`house-2` (`market_house.py prepare/build --set house-2`) исправляет цвет по материалам: балка задаёт T_oak, три каменных модуля имеют общие усиления, WALL/WINDOW — общие усиления дуба и штукатурки. `oak_masks` использует ln Y → Gaussian σ6 с заворотом по осям стыков → общий Оцу → сигмоиду ширины 0,3; цветового условия нет. Усиления панелей совместно сохраняют площадь-взвешенный общий цвет и средний конечного дерева на маске >0,5. Все шесть яркостей и дуб обеих панелей проходят ±25%; оценка верхних пятен в маске — 0,335% / 1,925% размеченной штукатурки. Реестр содержит 12 рецептов и те же 9 PNG; прежние записи и наборы сохранены. Одна новая игра той же сборкой: exit 0, три кадра, 12/12 замен, 0 целевых оригиналов. `--compose-house-2` переиспользует original/house-1 и пишет отдельные JPEG. [Маска, таблица и снимки](../reports/content/2026-10-market-house-concept/README.md#цвет-по-материалам-house-2).
