## Как снято

Окно игры мне не открыто, поэтому карту вызывала команда стенда `ai fate <kind>`, а окно снималось снаружи (`screencapture -l`). Сервер — подставной [`fate_probe.py`](fate_probe.py): отвечает на `fate_end` готовой картой (`FATE_FEATS` — сколько достижений, `FATE_DELAY` — задержка ответа). Гравюры — настоящие картинки летописца из `~/.local/share/gothic-ai/feats/` и эмблемы категорий.

```sh
uv run --with websockets python fate_probe.py 47898 server/src/gothic_ai/assets/feats/categories ~/.local/share/gothic-ai/feats
./shot.sh card3 death 34    # имя кадра, вид конца, секунд после загрузки мира до снимка
```

`winid.swift` — помощник `shot.sh`: id окна игры по pid (собирается `swiftc winid.swift -o winid`).

С задержкой ответа 40 с финал ушёл в главное меню без карты: карта ждёт до 30 с, как задумано.
