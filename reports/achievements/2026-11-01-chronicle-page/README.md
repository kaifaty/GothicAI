# Вкладка «Летопись» в дневнике, 2026-11-01

Проверка вида вкладки ([achievements.md](../../../docs/achievements.md#как-работает-сейчас), протокол v55) на Mac, кадрами окна игры.

Как снято: [`chronicle_probe.py`](chronicle_probe.py) — подставной ИИ-сервер, отвечает на `chronicle_get` образцом: три достижения судьбы (одно с показанным эпилогом) и две развилки других судеб. Картинки — две настоящие гравюры из `~/.local/share/gothic-ai/feats/`, остальные — эмблемы категорий. [`shot.sh`](shot.sh) запускает игру со стендом, который командой `diary chronicle <N> [open]` открывает дневник на вкладке. Игра в дневнике на паузе вместе со стендом, поэтому кадр окна снимается снаружи (`screencapture -l`, номер окна — [`winid.swift`](winid.swift)). Окно 1600×1200, новая игра.

```
uv run --with websockets python chronicle_probe.py 47899 server/src/gothic_ai/assets/feats/categories ~/.local/share/gothic-ai/feats
swiftc winid.swift -o winid
GOTHIC_DIR=<Gothic II> ./shot.sh list "chronicle 4"
GOTHIC_DIR=<Gothic II> ./shot.sh open0 "chronicle 0 open"
```

- [`list.jpg`](list.jpg) — список: судьба, «Другие судьбы», развилки «Глава 2, день 5» и «Глава 1, день 1»; выбрано «Пощадил вора» (ярче остальных). Вкладка «Летопись» — пятой под «Общей информацией», с рамкой; дата и время ниже неё.
- [`open0.jpg`](open0.jpg) — запись своей судьбы: гравюра, название в две строки, строка и показанный эпилог («Позже Лотар сам увидел живых волков…»).
- [`open3.jpg`](open3.jpg) — запись другой судьбы с настоящей гравюрой: «Другая судьба: глава 2, день 5».

Что поправлено по первым кадрам: вкладка наезжала на дату и время (их теперь сдвигает на шаг вниз); у вкладки не было рамки (рамки — часть фона дневника, полоса с линией копируется на шаг ниже, только в левой колонке); длинное название и строка «Другая судьба…» обрезались до одной строки.

Имя NPC в фокусе («Ксардас») просвечивает сквозь дневник — так в оригинальном дневнике OpenGothic, вкладка тут ни при чём.
