# Концы других судеб во вкладке «Летопись», 2026-11-01

Проверка вида итогов других судеб ([achievements.md](../../../docs/achievements.md#как-работает-сейчас), протокол v57) на Mac, кадрами окна игры. Пользователь решил показывать конец только у судеб с подвигами: голые смерти без поступков в летопись не попадают.

Как снято — как [вкладка](../2026-11-01-chronicle-page/README.md): [`chronicle_probe.py`](chronicle_probe.py) — подставной сервер с теми же судьбами, у развилок добавлены `ends`: смерть от бандита с длинной строкой летописца (глава 2) и гнев Ксардаса с запасной строкой (глава 1). [`shot.sh`](shot.sh) и [`winid.swift`](winid.swift) — те же. Окно 1600×1200, новая игра.

```
uv run --with websockets python chronicle_probe.py 47899 server/src/gothic_ai/assets/feats/categories ~/.local/share/gothic-ai/feats
swiftc winid.swift -o winid
GOTHIC_DIR=<Gothic II> ./shot.sh list "chronicle 5"
GOTHIC_DIR=<Gothic II> ./shot.sh open5 "chronicle 5 open"
GOTHIC_DIR=<Gothic II> ./shot.sh open7 "chronicle 7 open"
```

- [`list.jpg`](list.jpg) — список: под подвигами развилки «Глава 2, день 5» строка «Итог: Кровь на мельнице» («Итог:» тусклым, имя судьбы на месте названия, без иконки); она выбрана.
- [`open5.jpg`](open5.jpg) — открытый итог: имя судьбы, «Другая судьба: глава 2, день 6», «Смерть героя. Убийца: Бандит», строка летописца в пять строк.
- [`open7.jpg`](open7.jpg) — гнев Ксардаса: «Вечная служба», «Гнев Ксардаса», запасная строка.

Что поправлено по первым кадрам: текст итога занимал три четверти панели, и «глава 2, день 6» и имя убийцы переносились на вторую строку; теперь он во всю ширину.
