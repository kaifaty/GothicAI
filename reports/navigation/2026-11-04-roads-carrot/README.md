# Морковка знакомых дорог: окно проекции

2026-11-04. Прогресс по знакомому маршруту ищется только в окне вокруг текущего. Скачков прогресса больше окна было 28 на 357 232 записанных решениях; при повторе новым правилом — 0. Дальних первичных проекций было 57, стало 0. Где скачков не было, морковка совпала во всех решениях, кроме одного. На 60 маршрутах point v5 доехала 51 против 50, в 05-wall-pocket — 2/3 против 1/3. Перестройка маршрута при уходе от него не менялась. Поэтому в 05-wall-pocket, seed 18102029, событие на 2,4 с осталось (раздел «05-wall-pocket»).

## Правка

[`KnownRoads::updateGuidance`](../../../OpenGothic/common/game/knownroads.cpp), коммит `9c7de25c`:

- Прогресс — ближайшая точка ломаной на отрезке маршрута `[progress − 6,5 м, progress + 6,5 м]`; прогресс по-прежнему только растёт. Раньше ближайшая точка искалась по всей ломаной.
- После перестройки проекция ищется на первых `startOffset + 6,5 м` маршрута. `startOffset` — расстояние от NPC до первого узла (`Path::startOffsetCm`). Раньше — по всей ломаной.
- Уход дальше 8 м по-прежнему меряется от всей ломаной. Поэтому на той же траектории перестройки происходят в тех же решениях, пока не меняется момент перехода за знакомое (`beyond_known`).
- Поля входа сети, учитель и `navdemos.cpp` не менялись. Ветку follow в `guidanceFor` правка не задевает: там дороги не используются.

**Размер окна.** `guidanceWindowCm = 650` = lookahead 600 см + наибольший записанный шаг NPC за одно решение (100 мс) по XZ. Шаги по `trajectory.txt` тех же наборов, что в таблице ниже:

| Набор | Шагов | Медиана, см | 99-й процентиль, см | 99,9-й процентиль, см | Максимум, см |
|---|---:|---:|---:|---:|---:|
| point run (v5, HD) | 90445 | 13,83 | 42,66 | 43,34 | 47,98 |
| point walk (v5, HD) | 249825 | 5,07 | 21,43 | 31,55 | 50,35 |
| живые места (v5, HD, учитель) | 16664 | 11,82 | 42,56 | 43,34 | 44,70 |

Запас назад равен окну. Он не может уменьшить прогресс, но не даёт ему расти, пока ближайшая точка позади. Замер на эпизодах, где старое правило не прыгало: при запасе 0/1/2/4 м новый прогресс расходился со старым в 7/5/5/2 эпизодах (2150/2109/2109/1812 решений). NPC стоял позади, а ближайшая точка окна была впереди. При 6,5 м расходится одно решение, при 10 м — ни одного. Эти варианты мерились на промежуточной версии с первичным окном `[0, 6,5 м]`; итоговую версию проверяет таблица ниже.

## Повтор записанных траекторий

[`nav_roads_carrot.py`](../../../scripts/nav_roads_carrot.py) собирает [`nav_roads_carrot.cpp`](../../../scripts/nav_roads_carrot.cpp) с `knownroads.{h,cpp}` двух ревизий. Это `origin/main` `d61ca9cb` и ветка (код `9c7de25c`). Обе версии проходят одни и те же записанные позиции решений из `trajectory.txt`. Знания NPC строятся заново из `roads-events.jsonl` (узлы распорядка, spawn, чужак), граф — `roads-graph.json` стенда. Число знакомых узлов и рёбер сверяется с записанным во всех эпизодах. Старая ревизия воспроизводит записанный `carrot_cm` живых мест с ошибкой не больше 0,0011 см.

- **Скачок** — решение без перестройки, где прогресс вырос больше чем на 650 см.
- **Дальняя первичная проекция** — перестройка, после которой прогресс больше `startOffset + 650 см`.
- **Наползание** — решение, где прогресс за 1 с (без перестройки) вырос больше пройденного NPC пути по XZ плюс 650 см.

Команда (результаты — [`replay.json`](replay.json), полные — `/mnt/shared/gothic-ai/nav-roads-carrot/replay-recorded.json`):

```
python3 scripts/nav_roads_carrot.py --graph roads-graph.json --jump-cm 650 \
  --revision before=origin/main --revision after=WORKTREE \
  --set point-v5-run=/mnt/shared/gothic-ai/nav-pace-v5/results/v5-run/validation/point ... \
  --output replay-recorded.json
```

## Ограничения

- Перестройка при уходе дальше 8 м начинает маршрут с ближайшего по прямой знакомого узла. В 05-wall-pocket этот узел за стеной: v5 18102029 на 2,4 с, HD 18102028 на 4,5 с, после правки v5 18102028 на 21,6 и 79,5 с. Правка его не меняет.
- Окно ограничивает прирост прогресса за одно решение. За несколько решений подряд прогресс может пройти к участку, который проходит рядом, если маршрут в окне всё время приближается к NPC. Таких решений 124 на повторе, все в эпизодах, где раньше были скачки или дальние первичные проекции.
- Окно 6,5 м привязано к шагу решения 100 мс и записанной скорости NPC. При другом шаге или более быстром теле его нужно пересчитать.
