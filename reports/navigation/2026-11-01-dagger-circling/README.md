# Офлайн-разбор кружения DAgger4 r1 — 2026-11-01

DAgger содержит меньше меток forward: **47,82%** против **71,91% / 76,94%** в v4/v5, и больше turn_only: **13,81%** против **10,06% / 7,11%**. При этом соседние противоположные повороты встречаются **реже**: **6,74%** против **13,68% / 11,43%**. Takeover `heading` даёт forward в **88,83%**, turn_only — в **3,42%** решений.

При фиксированном ниже критерии близости входов найдены **153909 пар** с противоположными поворотами; в них участвуют **41069/568845 решений (7,22%)**. Такие решения в среднем ближе к двухсекундному пути учителя и реже имеют записанный stall, чем остальные. В живом stranger-прогоне цель во входе сохраняется, но после 30 с r1 часто выбирает отсутствие forward и поворот от цели, в том числе с вероятностями выше 0,997. Причинную связь этих действий именно с найденными парами меток офлайн-анализ не устанавливает.

## Данные и определения

Прочитаны только готовые данные на Mac через `/Volumes/shared/gothic-ai` (тот же NAS, что `/mnt/shared/gothic-ai` на Ryzen). Новых заявок gq, игр, обучения и вывода политики: **0**.

- v4: `/mnt/shared/gothic-ai/archive/nav-demos-v4-20261029`, ровно `splits.train` — **602 эпизода / 405626 решений**.
- v5: **700 / 405599**, ровно `splits.train` из `/mnt/shared/gothic-ai/nav-demos-v5/manifest.json`. Обучение читало XZ-копию `/mnt/shared/gothic-ai/nav-lean-data/corpus-v5`. Анализ берёт совместные метки и порядок из исходных `actions.txt`; дополнительно сверяет для всех 700 XZ-эпизодов исходный SHA из метаданных, число решений и гистограммы forward/strafe/turn/walk.
- DAgger: `/mnt/shared/gothic-ai/nav-dagger4/round1/phase-{1…6}/dagger`, **600 / 568845**. Метки — `keys` из NAVDEMO; управление и takeover — `samples.jsonl`, соединение по точному `time_ms`. Итог сверяется с `control-metrics.json`; список постановок — `round1-train.jsonl`.
- Живые записи: `/mnt/shared/gothic-ai/nav-live/dagger4-r1/{dagger4-r1,HD}/10-local-stranger/seed-18102029` и `05-wall-pocket/seed-18102027`. Wall seed выбран из неуспешных r1-прогонов; HD с тем же seed приехал.

В нативных v4/v5 `executePolicy()` возвращает `sample.keys`: `actions.txt[:decisions]` совпадает с метками; последняя остановка без NAVDEMO исключена. В DAgger `keys` всегда являются **меткой учителя**, включая шаги под управлением ученика; `previous_keys` — реально удерживаемая команда. Поэтому таблицы ниже не являются распределением исполненных DAgger-действий. См. [`navdemos.cpp`](../../../OpenGothic/common/navdemos.cpp), `executePolicy`, `mixTeacher`, `finish`.

Доли считаются по решениям, без усреднения долей эпизодов. `forward`: forward>0; `turn_only`: forward=strafe=0 и turn≠0; `walk`: сам флаг walk, включая остановки; `idle`: forward=strafe=turn=jump=climb=0, walk не учитывается. Это пересекающиеся признаки. `turn_only` не исключает jump/climb. Смена знака — строго turn(t)·turn(t+100 мс)<0; переходы через turn=0 не считаются. В подгруппе обе соседние метки должны принадлежать ей: удаление чужих строк не создаёт новых соседей. Разрывы между эпизодами исключены.

## 2. Противоположные метки при близких входах

Критерий задан до расчёта: все неупорядоченные пары **внутри одного эпизода**, без временного ограничения и выборки; turn имеют противоположные ненулевые знаки. Угол между трёхмерными единичными направлениями цели ≤5°, разность расстояний до цели ≤50 см. Центральные 8×8 м near-карты (32×32 исходные клетки по 25 см), семь вероятностных каналов, усредняются блоками 8×8 до сетки 4×4: средняя абсолютная разность всех 112 значений ≤0,02, максимальная ≤0,10.

## 3. Цель во входе и действия живых r1/HD

Скалярный вектор roads не хранится в `live-observations.bin.gz`: там карты и лучи. Направление и расстояние восстановлены из `goal_cm−position_cm` и `yaw_deg` тем же преобразованием, что в `navdemos.cpp`: x вправо, y вверх, z вперёд; нормализация по полному 3D-расстоянию. Вход расстояния — clip(см/1000,0,50), а не метры. Направление занимает vector[2146:2149], расстояние — [2149] при 238 лучах. Все восстановленные направления ненулевые; расстояние нигде не достигает отсечки 50.

Угол — atan2(x,z). «Поворот от цели» означает turn·угол>0 при |угол|>10°. Это геометрическая проверка команды, а не оценка правильности обхода препятствия. Effective forward дополнительно требует strafe=0: в движке strafe имеет приоритет перед forward.

## Воспроизведение и проверка

[`scripts/nav_dagger_circling.py`](../../../scripts/nav_dagger_circling.py) выдаёт JSON со счётчиками, знаменателями, совпадающими парами и четырьмя живыми трассами. Входные файлы открываются только на чтение.

```sh
uv run --with numpy --with pillow python scripts/nav_dagger_circling.py \
  --shared-root /Volumes/shared/gothic-ai > /tmp/nav-circling.json
uv run --with numpy --with pytest python -m pytest scripts/tests/test_nav_bc_data.py -q
```

Синтетический пример дописан в существующий `test_nav_bc_data.py`: противоположные метки при близком входе, отсечение другой карты/дистанции, соседство по управлению и расстояние до отрезка. **32 теста прошли**. Полный проход DAgger проверил **600 эпизодов / 568845 меток**, без пропуска фаз; несовпадений времени и итоговых счётчиков — **0**.
