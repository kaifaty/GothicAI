# 1г, шаг 1: цена MetalFX Temporal на нашем кадре (5.11.2026)

Продолжает [исследование 1г](README.md). MetalFX Temporal встроен за переключателем для замера (`OPENGOTHIC_UPSCALE=temporal`, [реестр](../../../docs/features.md)), векторы движения — только камеры. По умолчанию ничего не меняется.

## Итог

- **MetalFX Temporal на M1 Pro дорог.** При 50 % он стоит ≈5–6 мс на кадр против порога ≈2 мс.
- **Кадр с ним не дешевле нынешнего:** 21,2 мс против 19,3–22,2 у «сейчас» (75 %, TAA + MetalFX Spatial).
- **Кадр мягче полного разрешения:** чёткость 0,65 на рынке и 0,88 в интерьере против ограждения 0,9. Смещение мипов почти ни при чём: −2 / −1 / 0 дают на рынке 0,65 / 0,64 / 0,61. Мягкость даёт сам MetalFX: он сглаживает мелкую фактуру камня.
- **По правилу заметки дальше — свой TAAU,** общий с Vulkan, со своим замером.
- **Сама отрисовка в 50 % окупается:** без MetalFX кадр стоит 16,5 мс, на ≈4 мс дешевле «сейчас» в интерьере при `-vsm 0`. Этот запас и должен забрать свой TAAU.

## Что встроено

- **Tempest.**
  - `Encoder::upscaleTemporal` и свойство устройства `temporalUpscale`.
  - Формат RG16F, только на Metal.
  - Объект апскейлера пересоздаётся только при смене размеров и форматов.
  - Энкодеры MetalFX не принимают счётчиков, поэтому их строка в профиле — промежуток между соседними проходами ([performance.md](../../../docs/performance.md)).
- **Движок.** MetalFX стоит на месте резолва TAA.
  - Векторы камеры пишет `shader/upscale/motion_camera.frag`.
  - Халтон (2, 3) на ⌈8·(выход/вход)²⌉ фаз, смещение мипов log2(вход/выход) − 1.
  - Блум и тонмаппинг идут в разрешении экрана; блум смешивается в тонмаппинге (`tonemapping.frag -DBLOOM`).
  - MetalFX принимает `sceneLinear` R11G11B10 как есть, без копии.
- **Знак смещения подтверждён:** центр пикселя минус точка выборки. Неподвижная сцена не сдвигается. Три других знака сдвигают кадр на 0,5–2 px.
- **На macOS 27 MetalFX Temporal — нейросеть**: в стеке `_MFXTemporalScalingEffectV4`, MPSGraph и компиляция под Neural Engine.
  - Первое создание апскейлера заняло больше минуты; потом — 0,47–0,7 с.
  - Ждёт ли GPU внутри интервала MetalFX работу Neural Engine, не проверено: ответит Metal System Trace одного кадра.

## Без переключателя кадр прежний

- **Интерьер:** 0 отличающихся пикселей во всех пяти кадрах, против main и против повтора.
- **Рынок:** до 69 пикселей, наибольшее отличие 4/255. Это шум самой сцены: два прогона одного main дают 0–198 пикселей.

  - Брусчатка у MetalFX заметно мягче и 100 %, и «сейчас».

## Цена

Интерьер, `-vsm 0`, drawable 3456×1918, `GPU mean` в мс.

| Вариант | Чистые прогоны | Прогоны рядом с чужими играми |
|---|---|---|
| «сейчас» (75 %, TAA + Spatial) | 20,8; 22,2; 19,3 | 25,9 |
| MetalFX 50 % | 21,2 | 24,6–25,7 (пять прогонов) |
| те же 50 % без MetalFX (`OPENGOTHIC_GPU_SKIP=Upscale-temporal`) | 16,5 | 18,0 |

- **Интервал MetalFX** — до начала фрагментов следующего прохода: медиана 5,8 мс в чистом прогоне, 6,4–6,7 мс в остальных. Вычитанием выходит ≈4,7 мс.
- **Что уходит из кадра:** TAA и его резкость, 1,14 + 0,38 мс. Освещение дешевеет с 2,1 до 1,1–1,2 мс.
- **Что добавляется:** векторы камеры ≈0,1 мс.
- **Что дорожает в разрешении экрана:**
  - блум — 0,61–0,71 мс фрагментов против 0,40–0,43;
  - тонмаппинг с блумом — 0,35–0,38 мс против 0,13 + 0,27 у тонмаппинга и Spatial.

Mac делили другие сессии: из шести прогонов MetalFX чистый только один. Полной таблицы по рынку, лесу, 67 / 75 % и `-vsm 1` нет: она не нужна для решения, MetalFX не проходит порог и на одном месте.
