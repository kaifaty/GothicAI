# Временное сглаживание (TAA) и временной апскейл: исследование (3.11.2026)

Этап 1 [плана графики](../../../docs/graphics-plan.md). В проекте TAA ещё не делали, рецепта в `docs/` нет, поэтому сначала — исследование по правилу [AGENTS.md](../../../AGENTS.md).

## Цель

Картинка без мерцания краёв, листвы и бликов, сравнимая по чёткости с суперсэмплингом. Это основа для следующих шагов:
- SSAO, туман и будущие SSGI и SSR можно считать с меньшим числом выборок и копить по кадрам;
- пониженное разрешение перестаёт быть мылом: временной апскейл собирает полный кадр из нескольких смещённых.

Второе важно для Mac. На Retina M1 Pro улица стоит 25–41 мс GPU на кадр, а 50 % разрешения снижает это до 15–19 мс ([performance.md](../../../docs/performance.md)). Сейчас пониженное разрешение растягивает MetalFX Spatial, без новых деталей.

## Эталон

- **Неподвижный кадр:** сошедшийся TAA близок к суперсэмплингу 8–16 выборок на пиксель. Каждый кадр камера сдвигается на долю пикселя по последовательности Холтона (2, 3), история копится с весом около 0,9: новый кадр даёт ~10 %. После ~16 кадров вклад первого кадра меньше 20 % ([Karis 2014](#источники)).
- **Движение:** края не «ползут лесенкой», листва и тонкие линии (верёвки, перила, ветки) не мерцают. За движущимся NPC нет шлейфа: в кадре, где открылся фон, он не мутный дольше нескольких кадров.
- **Цена:** один полноэкранный проход: окно 3×3 текущего кадра и бикубическая выборка истории. Свою цену меряем сами через `perf.sh` и `OPENGOTHIC_GPU_SKIP`. Чужим числам для Metal не доверяем.

## Как делают другие и где ловушки

- **Схема UE4** ([Karis 2014](#источники)) стала стандартом:
  - смещение проекции по субпикселю;
  - история перепроецируется по векторам движения;
  - вектор берётся у ближайшего по глубине пикселя окна 3×3, иначе края движущихся объектов теряют свой вектор;
  - история читается фильтром Catmull-Rom, а не билинейным, иначе каждый кадр она мылится;
  - история обрезается по цветам окрестности в YCoCg;
  - вес кадра — по обратной яркости: одна яркая искра не прожигает историю.
- **Обрезка по дисперсии** ([Salvi 2016](https://developer.download.nvidia.com/gameworks/events/GDC2016/msalvi_temporal_supersampling.pdf)): коробку цвета строят по среднему и отклонению окна, она теснее AABB. Ловушка — параметр γ. Высокий γ даёт шлейфы, низкий возвращает дрожание. Новые работы предлагают ещё более тесные оболочки ([Ikkala 2024](https://webpages.tuni.fi/vga/publications/k_DOP_clipping_Ikkala2024.pdf)). Обзор приёмов и их провалов — [Yang, Liu, Salvi 2020](https://research.nvidia.com/labs/rtr/publication/yang2020survey).
- **Главные источники брака** ([обзор](https://research.nvidia.com/labs/rtr/publication/yang2020survey)):
  - открытие фона (disocclusion);
  - тонкая геометрия: она есть в одних смещениях и пропадает в других;
  - неверные векторы движения. Объект двигался, а вектор посчитан только по камере — получается шлейф.
- **Полупрозрачное** не пишет глубину и векторов не имеет: дым, огонь, частицы, вода. FSR2 для этого принимает маску реактивности (насколько не доверять истории) и маску прозрачности. Маску можно получить сам: сравнить копию кадра до полупрозрачного с итогом ([FSR2](https://gpuopen.com/?p=61401)).
- **Резкие смены кадра** — смена камеры в диалоге, телепорт, загрузка — требуют сброса истории, иначе один кадр будет призраком прошлого.
- **Мыло.** Даже хороший TAA размывает. Обычно после него стоит лёгкое повышение резкости (CAS или RCAS). Отдельно проверяем, что текстуры не теряют деталь: смещение мипов на −0,5…−1 при апскейле.
- **MetalFX Temporal** ([Apple](https://developer.apple.com/documentation/metalfx/mtlfxtemporalscalerdescriptor/isoutputresolutionmotionvectorsenabled.md)): апскейлер Apple с тем же входом — цвет, глубина, векторы движения, смещение камеры, маска реактивности, экспозиция. Заголовки `MTLFXTemporalScaler.hpp` уже лежат в `lib/Tempest/Engine/thirdparty/metal-cpp/MetalFX/`, Spatial-версия уже подключена. На Vulkan своё: на 3080 у GPU большой запас, хватит своего TAAU, FSR не нужен.

## Что умеет наш движок

Сверено по коду.

| Нужно | Есть | Где |
|---|---|---|
| Смещение проекции | нет. `Renderer::updateCamera` берёт `camera.projective()` и `viewProj()` как есть | `common/graphics/renderer.cpp` |
| Прошлая матрица камеры | нет. `SceneGlobals` хранит только текущие `viewProject`/`viewProjectInv` и их варианты LWC | `sceneglobals.*` |
| Векторы движения | нет. G-буфер: `gbufDiffuse` RGBA8, `gbufNormal` R32U, `gbufOrm` RGBA8, глубина | `renderer.cpp`, `shader/materials/main.frag` |
| Прошлые матрицы объектов и костей | нет. `InstanceStorage` — один SSBO, правки кладёт `patch.comp`. Прошлой копии нет, при стриминге Id выделяются и освобождаются | `instancestorage.*` |
| Движение вершин без матриц | ветер у статичных мешей, волны Гёрстнера у воды, ткань, морфы лиц | `vertex_process.glsl`, `water/`, `clothvisual.*` |
| Место для резолва | есть: после полупрозрачного и подводного прохода, до блума и тонмаппинга, в линейном `sceneLinear` R11G11B10 | `Renderer::draw` |
| Копия кадра до полупрозрачного | есть точка: перед `drawTranslucent` | `Renderer::draw` |
| Пониженное разрешение и апскейл | есть: `vidResIndex` 75 % и 50 %; MetalFX Spatial (`cmd.upscale`) или Lanczos в тонмаппинге | `renderer.cpp`, `gapi/metal/mtcommandbuffer.cpp` |
| CMAA2 | есть, `-aa 1` по умолчанию. При TAA выключается | `drawCMAA2` |
| Съёмка и замер | `shot`, `rec`, `perf.sh`, интервалы GPU на Metal | `testbench.cpp`, `scripts/` |

Пробелы: смещение камеры, прошлые матрицы камеры и объектов, вектор движения в G-буфере, история и её сброс, маска полупрозрачного.

## Как сделать — подшаги

Каждый подшаг — свой PR, включается флагом, пока пользователь не принял вид.

1. **1а — TAA по камере.**
   - Смещение Холтона (8 фаз) только у главной проекции. Тени, HiZ прошлого кадра и UI не смещаются.
   - Прошлая матрица камеры без смещения.
   - Вектор статики считается в резолве из глубины.
   - Резолв по схеме Karis + Salvi: ближайший вектор 3×3, Catmull-Rom, обрезка в YCoCg, вес по яркости.
   - Сброс истории при смене камеры, телепорте и загрузке. CMAA2 при TAA выключается.

   Шлейфы за NPC здесь ожидаемы: их сдерживает обрезка, а чинит 1б.
2. **1б — векторы движения объектов.**
   - Вложение RG16F в G-буфере; вершинный шейдер считает и прошлую позицию.
   - Прошлые матрицы объектов и костей — копия `InstanceStorage` до правки кадра. Новый Id получает прошлое = текущее.
   - Ветер и волны — по прошлому времени. Обе ветки: вершинная и меш-шейдерная (`-ms`).
3. **1в — полупрозрачное и резкость.**
   - Маска реактивности из разницы кадра до и после полупрозрачного.
   - RCAS после резолва и смещение мипов −0,5 перенесены в 1а (ревью клипов 2026-11-04, [отчёт 1а](step-1a.md#резкость-замер-по-клипам)); здесь остаётся смещение мипов под пониженное разрешение.
4. **1г — временной апскейл.**
   - MetalFX Temporal на Mac: те же вход, векторы и маска.
   - Свой TAAU на Vulkan.
   - Пресет Mac — 67 % или 50 % внутреннего разрешения, по замеру.
5. **1д — тонмаппер и грейдинг.** Отдельное короткое исследование. Обратный ACES в `textureAlbedo()` держит вид оригинальных текстур, поэтому смена кривой не должна их сдвинуть.

## Приёмка

Вид принимает пользователь по клипу «CMAA2 | TAA» рядом, не по стоп-кадру. Числа — ограничители.

- **Стенд** (подшаг 0 плана графики): `rec`-клипы одних и тех же мест.
  - Рынок: герой идёт за камерой `cam follow`, вокруг прохожие.
  - Лесная дорога: листва и ветер.
  - Медленный поворот камеры на месте: края крыш, верёвки, перила.
  - Ночь у жаровни: огонь и дым.
  - Плюс стоп-кадры `perf-shot`.
- **Мерцание:** при неподвижной камере на неподвижной сцене средняя разница яркости соседних кадров. У TAA она должна быть заметно ниже, чем у CMAA2. Листву, которая качается сама, исключаем маской.
- **Чёткость** сошедшегося стоп-кадра: энергия градиента не ниже ~0,9 от CMAA2, после CAS.
- **Шлейф:** за идущим NPC на контрастном фоне — по клипу, глазом. После 1б — не дольше 2–3 кадров.
- **Цена:** GPU-время `perf.sh` (рынок, лес, интерьер) с TAA и без. На Mac также цена прохода вычитанием. Для 1г — выигрыш кадра на 67 % и 50 % при виде, который пользователь принял.
