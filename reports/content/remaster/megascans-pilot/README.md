# Пилот Megascans: глыба и земля

Проба, 2026-11-06. В рабочий контент не входит. Файлы сканов лежат вне git: лицензия Fab запрещает раздавать их отдельно. Здесь только код, числа и выводы. Ролик по итогам: [23 000 сканов снова бесплатно](https://youtu.be/Y_78G-7cVJQ).

## Цель

Узнать на настоящем кадре из игры, что сканы дают Хоринису и чего это стоит, и не становится ли место чужим. Приёмка — глаз пользователя на паре кадров и клипе, числа только ограничители.

## Что пробовали

| | Оригинал | Скан |
|---|---|---|
| Глыба у фермы Лобарта | `NW_NATURE_STONE_BIGHIGH_01`: 40 треугольников, 6,5 × 2,9 × 6,4 м, 85 штук в Хоринисе, текстура 512 px | Megascans: 44 060 треугольников, 4096 px, высота 2,54 м против 2,94 |
| Лесная земля | `NW_NATURE_WALDBODEN_03`: 512 px на 5 м | Forest Floor, Megascans: 3 × 3 м, 8K в источнике |
| Глыба, проверка свободным сканом | то же | `boulder_01` с Poly Haven (CC0): 1,3 × 1,8 × 1,0 м, увеличен в 3,4 раза, 61 010 вершин в GLB |

## Итоги

**Глыба работает.** Дыр нет, цвет подогнан усилением к среднему оригинала. Форма другая: расколотый камень с навесом вместо гладкого купола. Blender на 12 000 треугольников давал складки и дыры, поэтому упрощение в MeshLab; ниже 44 тысяч оно не опустилось, держат швы UV.

**Земля с первого раза не вышла, но пробован один скан из многих.** Вблизи убедительно, издалека оригинал лучше всех трёх вариантов: как есть, с подогнанным цветом и с пятнами оригинала. Нарисованная трава с папоротником передаёт объём, которого нет в плоском скане почвы. Похоже, нужна настоящая трава (пункт 4 [плана графики](../../../../docs/graphics-plan.md)), а не третий круг цветокоррекции.

**CC0 тоже подходит.** Камень с Poly Haven того же класса: рельефа больше, но цвет пестрее, мха нет, с ракурса 225° силуэт как стопка плиток, а увеличение делает трещины крупными. Пробован один скан, подбор не делался. Megascans даёт выбор и глыбы нужного размера без увеличения, CC0 даёт раздачу без условий Fab.

## Цена

Ryzen, RTX 3080, 1080×1920, глыба заполняет кадр, 30 с:

| Набор | Кадр, мс | Класс очереди |
|---|---|---|
| Оригинал | 9,95 | тихий |
| Megascans | 9,78 | тихий |
| Poly Haven | 10,08 | не тихий, разница в пределах шума |

Глыба занимает 44 МБ текстур против меньше 1 МБ. В кадре одна такая глыба: Mac и много глыб сразу не мерены, на всём мире их 85, LOD для GLB нет.

## Ловушки

- **Предел GLB.** Движок берёт не больше 65 535 позиций и 65 535 вершин с атрибутами на материал (`OpenGothic/common/gltfmesh.cpp`). Сверх предела он пишет `meshes: unable to replace` и молча показывает оригинал, поэтому после съёмки ищи эту строку в `game.log`.
- **Плотная развёртка держит упрощение.** Скан Poly Haven не упрощался с сохранением UV. Рабочий путь — упрощение без UV, новая развёртка и запекание цвета, нормалей и ORM: `scan_decimate.py ... plain`, затем `scan_rock.py --diffuse --arm`. Само упрощение почти не сработало (66 122 → 65 526 треугольников), причина не разобрана.
- **Средний цвет считай только по запечённым текселям.** Чёрные щели развёртки сбили усиление: 1,37/1,92/1,48 вместо 0,76/1,06/0,82, и камень вышел слишком светлым.
- **`rock_moss_set_*` и `rock_face_*` с Poly Haven — не глыбы:** это россыпи камней и куски склона. Размер в карточке там относится к раскладке.

## Как повторить

Сканы кладутся вручную в `~/.local/share/gothic-ai/content-sources/`.

```sh
uv run --no-project --with numpy --with pillow --with scipy python scripts/content/megascans_pilot.py check
uv run --no-project --with numpy --with pillow --with scipy python scripts/content/megascans_pilot.py build megascans-pilot-3 --size 4096
uv run --no-project --with numpy --with pillow --with scipy python scripts/content/polyhaven_pilot.py polyhaven-pilot-1
BENCH_HOST=ryzen TEMPEST_WINDOW_SIZE=1080x1920 OPENGOTHIC_CONTENT=<набор> scripts/bench.sh scripts/bench/megascans-pilot.bench <папка>
```

`megascans-clip.bench` снимает облёт глыбы. Пустой `OPENGOTHIC_CONTENT=` даёт оригинал. Копии сканов на Ryzen убирает `scripts/ryzen.sh clean`.
