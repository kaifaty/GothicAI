# P30: восемь повторов на Mac для ролика

19 октября 2026 года. **Готовы 8/8 дублей:** seeds 100000–100003 на открытой арене,
100004–100007 у стены. Все прошли критерий съёмки: `identical_commands=1`,
`same_outcome=1`, отклонённых команд 0, одинаковые HP и время боя.

Всего совпали 138 принятых команд и 414/414 событий их исполнения. `same_outcome`
в скрипте сравнивает только причину завершения, поэтому отдельно проверены наличие
terminal, исход, HP обоих участников, признаки завершения и `elapsed_game_ms` — 8/8.
Везде `opponent_down`; HP 300/0, кроме 100003 с теми же 294/0. Время боя совпало
для каждого seed: от 7233 до 12733 мс.

Решения те же, но физика Mac и Ryzen численно различается. Координаты финала
расходятся на доли миллиметра: максимальная дельта одной координаты — 0,869 мм.
Максимум пространственного смещения актёра — 1,077 мм, поворота — 0,001198°.

различия допустимы по принятому критерию; движок и строгий компаратор не менялись.

Первый разный шаг — первое отличие наблюдений, считая от reset (`sim_step=16`).
Δ позиции — максимум евклидова расстояния XYZ между финальными позициями двух актёров,
сопоставленных по роли. Δ поворота — максимум кратчайшей угловой разности с учётом ±180°.

Копии: `~/.local/share/gothic-ai/explain/combat-ai/footage/p30-<seed>/duel.mp4`
и `duel.wav`, все восемь seed. Проверены 8 MP4 **1920×1080, H.264, 30 кадров/с**
и 8 WAV **PCM 16 бит, stereo, 48000 Гц**, с ненулевым звуком игры; копии совпадают
с исходниками по SHA-256. Общая длительность видео — 105,43 с.

Оба движка — `main` на начало записи, `9e4dcae0`. Записи T=0 с журналами собраны
на Ryzen через `gq`, Jolt x86-64-v3; Mac — arm64, M1 Pro, Metal. Save скопирован
с Ryzen, ассеты и HD-текстуры — стандартные для Mac-стенда. Jolt работает без
фоновых потоков, RNG анимаций и скриптов изолированы. Перед каждым запуском
выполнялся `pgrep -fl Gothic2Notr || echo "no game"`; при занятой игре ожидали.

Съёмка из корня worktree, отдельно для каждого seed:

```bash
SOUND=1 MUSIC=0 WORLD_SOUNDS=0 \
OPENGOTHIC_FOOTIK_WATCHED_ONLY=1 OPENGOTHIC_ANIM_SKIP_FAR=1 OPENGOTHIC_FREEZE_WORLD=1 \
python3 scripts/body_replay_film.py render .bench/replay-mac/film/p30-$seed \
  --game OpenGothic/build/opengothic/Gothic2Notr \
  --assets '/Volumes/DevSSD/Dev/games/Gothic II' \
  --save .bench/replay-mac/save_slot_1.sav --size 1920x1080 \
  --textures /Users/kaifat/.local/share/gothic-ai/hd-textures/textures
```

Каждый дубль сравнен через `scripts/body_schedule_equivalence.py --realtime` с его
каталогом в `.bench/replay-mac/film/` и `--lockstep` с исходным эпизодом в
`.bench/replay-mac/recordings/`. Результаты — `.bench/replay-mac/equivalence-<seed>.json`.
Код 2 во всех восьми сравнениях означает несовпадение строгой физики; обе метрики
приёмки в каждом результате равны 1. Оригиналы журналов остаются и на Ryzen в
`~/gothic-ai/replay-mac/recordings/`.
