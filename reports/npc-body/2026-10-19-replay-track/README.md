# Трек головы и действия P30 для восьми Mac-дуэлей

Для seed 100000–100007 созданы `actions.json` рядом с уже снятыми роликами:
`~/.local/share/gothic-ai/explain/combat-ai/footage/p30-<seed>/actions.json`.
В каждом файле — 30 fps, размер 1920×1080, голова бандита и HP на каждом кадре,
а также команды P30 в момент `started`. Имена действий взяты из
`body-service/src/gothic_body/schema.py`. Всего 3163 кадра и 138 действий.

## Команды и тесты

`prepare --track-head` берёт script symbol первичного актёра из `reset_ready`
и добавляет трек перед `rec`. `labels` читает журналы без запуска игры:

```sh
python3 scripts/body_replay_film.py prepare NAME=EPISODE_DIR --output FILM_DIR --track-head
python3 scripts/body_replay_film.py labels FILM_DIR/NAME --output FOOTAGE_DIR/actions.json
cd body-service
uv run pytest -q ../scripts/tests/test_body_replay_film.py ../scripts/tests/test_body_schedule_equivalence.py
```

Результат: **22 passed in 1.10s**, exit 0. Тесты проверяют опцию трека,
кадровые часы, HP, фильтрацию первичного актёра, задержку между `accepted` и
`started`, имена действий, `null` вне кадра, путь вывода и отказ при неполных
или противоречивых журналах. Сборка Linux и все восемь рендеров — exit 0.

Размеры JPG (байт): `100000/0045` — 104941; `100000/0180` — 106551; `100000/0300` — 100417; `100004/0045` — 106280; `100004/0120` — 106995; `100004/0210` — 104807. Всего 629991 байт; каждый файл меньше 150000 байт.
