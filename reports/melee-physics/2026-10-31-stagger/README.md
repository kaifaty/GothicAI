# Два уровня равновесия людей — шаг 4 NRFTW

2026-10-31. Код механики: `28500b219`. Стенд: [`melee-stagger.bench`](../../../scripts/bench/melee-stagger.bench). Текущее поведение и выключатели — [physics.md](../../../docs/physics.md#как-работает-сейчас).

`[GAME] melee_stagger=1` действует вместе с `melee_posture=1`: шкала 100 оглушает стоя на 1500 мс, тяжёлое попадание по `posture` запускает прежний нокдаун. Бонус ×1,5 работает по всем трём причинам оглушения, порог учитывает класс надетой брони, замах 2H и удар сверху защищены от прерывания до конца окна клинка. OFF возвращает прежнюю механику. Вид, звери, монстры, входы P30, цены и правила парирования не менялись.

## Mac-смоук ON/OFF

Одна сборка, `NEWWORLD.ZEN`, seed 73013. Шкала заполняется командой `strike` через штатный `Npc::takeDamage`, без геометрии контакта; затем герой наносит настоящий боковой удар 1H или 2H через `press action` / `tap left`. Для попадания по оглушённому фиксируется положение цели; `pin` не выключает реакции тела. Удар 2H в режиме OFF становится штатным ударом сверху по уже лежащему.

```sh
BENCH_HOST=local WORLD=NEWWORLD.ZEN NO_BUILD=1 \
MELEE_POSTURE=1 MELEE_STAGGER=1 MELEE_PHYSICS_HITS=1 \
MELEE_PARRY=1 MELEE_PARRY_AI=1 OPENGOTHIC_BODY_TRACE=1 TIMEOUT=300 \
scripts/bench.sh melee-stagger .bench/melee-stagger-on2-20261031

BENCH_HOST=local WORLD=NEWWORLD.ZEN NO_BUILD=1 \
MELEE_POSTURE=1 MELEE_STAGGER=0 MELEE_PHYSICS_HITS=1 \
MELEE_PARRY=1 MELEE_PARRY_AI=1 OPENGOTHIC_BODY_TRACE=1 TIMEOUT=300 \
scripts/bench.sh melee-stagger .bench/melee-stagger-off-20261031
```

| Событие за сценарий | ON | OFF |
|---|---:|---:|
| Попадания / записи `damage` | 56 | 56 |
| `stun_start(reason=posture, duration_ms=1500)` / `stagger` | 3 | 0 |
| Оглушения `parried`, 1000 мс | 2 | 2 |
| Оглушения `guard_break`, 1000 мс | 1 | 1 |
| Нокдауны | 1 | 3 |
| Нокдауны `cause=heavy_on_staggered`, `heavy=two_handed` | 1 | 0 |
| Попадания с `stun_bonus=1.5` | 32 | 0 |
| Попадания с `super_armor=true` | 10 | 0 |
| Ошибки сценария | 0 | 0 |
| Код завершения `bench.sh` | 0 | 0 |

Числа взяты из `events.jsonl`, `run/melee-posture.jsonl` и `run/melee-blade-shadow.jsonl` в указанных локальных папках `.bench/` (не входят в git). `stun_bonus` — численный множитель 1 или 1,5; `super_armor` — булев признак.

- **Лёгкий удар:** при ON шкала бандита заполнилась на 2467 мс; оглушение закончилось на 3967 мс — ровно 1500 мс. Попадание `T_1HATTACKL` записало `stun_bonus=1.5`, урон 8; падений в этом сегменте 0. При OFF бандит упал на 2467 мс сразу от шкалы.
- **Тяжёлый удар:** второе оглушение бандита при ON началось на 13801 мс. Попадание `T_2HATTACKL` нанесло 19 урона с бонусом 1,5 и на 14534 мс запустило `heavy_on_staggered / two_handed`; в тот же момент записан `stun_end(reason=knockdown)`. Само падение HP не сняло: `knockdown_health` — 99131 → 99131. Подъём и восстановление завершились штатно. При OFF шкала уронила бандита уже на 13801 мс.
- **Другие причины:** два удара 2H по бандиту с причинами `parried` и `guard_break` и один удар бандита по оглушённому герою дали 3 бонуса ×1,5 при ON, без нокдаунов. Длительность каждого оглушения — 1000 мс. При OFF те же 3 оглушения сохранились, бонуса нет.
- **Супер-броня героя:** 10 попаданий по начатому замаху 2H записали `super_armor=true`, урон и шкала прошли. Десятое заполнило шкалу: `posture` на 26734 мс, конец на 28234 мс. Следующие 11 попаданий в этом сегменте получили бонус ×1,5. При OFF на 26734 мс герой сразу упал; записей супер-брони нет.
- **Журналы:** оба настоящих попадания клинком при ON имеют `stun_bonus=1.5`; все 32 бонуса присутствуют и в `defence_result`. При OFF все множители равны 1, все признаки супер-брони — false.

Подготовка потребовала одного повторения ON: исходный прогон `.bench/melee-stagger-on-20261031` дошёл до `done` и дал те же численные события, но оболочка завершилась с кодом 2, поскольку `bench.sh` был изменён во время его выполнения. Новый сценарий добавлен в существующий список `-nointro`; повтор ON и OFF запускались со стабильным скриптом и завершились с кодом 0. Это сбой подготовки, не отказ механики.

Матрица дуэлей на Ryzen не запускалась. Эти 56 попаданий на режим проверяют правила; частоту нокдаунов 0,2–0,5 на дуэль ими не оценивали. Запись видео и оценка вида не выполнялись.
