# Native NPC у сбитого противника — 29.10.2026

Приёмка **не пройдена**: после двух полных матриц native 2h всё ещё попадает сверху реже 60% и даёт один таймаут. Подбор остановлен по правилу двух неудачных проверок (`blocked`); ниже — измерения, без выводов о балансе.

## Что изменено

- В `Npc::implAttack` native NPC с 1h/2h очищает всю оставшуюся очередь `FightAlgo` у сбитой цели; начатый замах доигрывается. Очистка отдельная: прежний `onClearTarget()` оставляет хвост очереди.
- По лежащей цели NPC подходит, поворачивается и запускает обычный запрос `doAttack(Attack)`, который существующий `isMeleeDownStrike` переводит в `T_1HSFINISH` / `T_2HSFINISH`. Финальные пределы подхода: **165 см / 170 см**, по полной `fightDistanceTo`, с ограничением скриптовым `attackFinishDistance` (180 см на арене).
- По встающей цели NPC подходит до прежней дистанции оружия, если нужно, затем ждёт в стойке лицом к ней. После подъёма возвращается обычный `FightAlgo`.
- `[GAME] melee_down_tactics=1` по умолчанию; `toggle melee_down_tactics` в Marvin; `MELEE_DOWN_TACTICS=0|1` в стендах. Новая ветка требует также `melee_posture` и `melee_physics_hits`; OFF сохраняет прежний исполнитель. Герой, `bodyOverride`/P30, маски действий, анимации, магнит и числа механики не изменены.
- Отчёт аддитивно получил `swings_by_target_posture.lying/rising`, `overhead_swings` и образцы дистанций. Прежние поля сохранены.

## Почему NPC почти не выбирали удар сверху

Повторно разобран `balance-main-5749adc`: среди замахов по лежащему **63 обычных 1h и 47 обычных 2h**; все они начались дальше 180 см по полной 3D-дистанции между записанными корнями (минимум 184,77 / 180,25 см). При измерении только по земле ближе 180 см оказываются 17 / 36 из них. `isInFinishRange` использует 3D `fightDistanceTo`, поэтому горизонтальная близость не означала доступность добивания. У всех этих обычных окон `combo_index=0`: данные не подтверждают продолжение комбо как причину отказа конверсии. Удары сверху в том прогоне: 5 / 6. В новых журналах `diagnostic.start_distance_cm` записывает непосредственно `fightDistanceTo` при создании окна.
