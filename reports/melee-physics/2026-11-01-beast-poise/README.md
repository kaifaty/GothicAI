# Равновесие зверей по размеру — 2026-11-01

Вторая половина шага 4 [переноса боёвки NRFTW](../../Боёвка%20No%20Rest%20for%20the%20Wicked%20на%20рельсах%20Готики.md). Реализация: `bd78d042c`; затем исправлена только подготовка снеппера в стенде. Цель — проверить механику, без матрицы дуэлей и настройки баланса.

`[GAME] melee_beast_poise=1` действует при `melee_posture=1` и `melee_stagger=1`. Зверь — `isMonster()` без активного оружия. Итоговая `physicsMass()` определяет класс: <55 кг мелкий, [55, 300) средний, ≥300 огромный. Мелкий сохраняет прежнее вздрагивание. Средний и огромный сохраняют начатую атаку целиком. Полная шкала мелкого и среднего обнуляется и оглушает стоя на 1500 мс; удар человека по оглушённому получает ×1,5. Огромный шкалу не копит. Нокдауна зверей нет. Выносливость и накопление шкалы человека от ударов зверей не менялись. Вид оглушения остаётся Claude; в `meleeStunLook` добавлен только ранний выход для не-людей.

## Подготовка стенда

Два предварительных ON-прогона (`.bench/beast-poise-on`, `.bench/beast-poise-on-native`) завершились exit 0, но не проверяли укус: в каждом 0 решений FAI и 0 укусов. В первом принудительный `ani` запускался с `BS_STAND`; во втором смене состояния мешал `AI_REMOVEWEAPON`, оставленный `ZS_ATTACK_END` человеческой команды `fight`. Снеппер с Fist не может завершить эту команду, и `ZS_MM_ATTACK` оставался `waiting_for_state`. Причина разобрана по DAT и очереди, код игры не менялся. Итоговый стенд после задания цели дважды очищает остаток через `freeze`, запускает `ZS_MM_ATTACK` и снимает внешний контроль. Валидная подготовка подтверждена `native_choice`, `do_attack`, `S_FISTATTACK` и реальным уроном в обоих итоговых прогонах. Эти два прогона относятся к отладке подготовки, не к попыткам механики при верной подготовке.
