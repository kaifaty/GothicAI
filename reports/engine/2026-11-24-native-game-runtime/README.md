# Gothic II без Daedalus в штатной игре

Цель — сборки `Gothic2Notr` и `gothic-body-runner` без интерпретатора для проверенной «Ночи Ворона». Старые сохранения этой программы читаются штатной сборкой. `content-convert` и отдельная сборка совместимости продолжают работать с исходными DAT.

## Перепись входов

Исходное дерево — `733c85bfc`. Суточная проверка Хориниса, холодная цепочка действий героя и оконная проверка меню и загрузки уже давали ноль инструкций на соответствующих сценариях. Перепись ниже учитывает также чтение инструкций без их исполнения и использование VM как хранилища.

## Порядок работ

1. Перепись, строгий наблюдатель, записи без обращений к упакованному `MENU.DAT`.
2. Типизированное состояние и старый формат сохранения. Первый сквозной граф — Ларес, `DIA_ADDON_LARES_PATCH_INFO` → `B_GIVEINVITEMS`. Сравнение с исходной VM включает орнамент, уведомления и три сохраняемых значения разных типов.
3. Остальные точки входа, готовые программы и данные глав, единый исполнитель для штатного сюжета и ИИ-моста.
4. Два игровых бинарника без линковки VM и штатная база без записей исполняемых программ. Лаунчер переключается после проверки обоих артефактов. Прежний комплект остаётся способом отката.

## Промежуточный результат

- Штатное меню выбирает каталог по метаданным. Конвертер готовит 11 798 программ StoryGraph, 4 139 определений диалогов и 37 привязок реплик по умолчанию к 147 темам. У всех уникальных корней диалогов, 260 обработчиков предметов, 46 состояний интерактивных объектов и 61 триггера мира проверена полнота цепочки вызовов. Сервер читает готовый граф из проверенного манифеста базы.
- В импорт вынесены размещения глав Хориниса, Долины Рудников и Яркендара, три начальные группы Ирдората, региональные помещения, правила 50 торговцев, 123 выдачи трофеев и 206 обращений к журналу. Для отсутствующих записей старых баз действует совместимость.
- `placement.json` v7 содержит 90 размещений для 39 триггеров. Порядок вставок в 35 триггерах совпал с исходной VM, операнды остальных четырёх сверены с исходной программой. Каталог загружается с пустым байткодом. Старые базы выполняют исходные функции триггеров.
- Формат `game/daedalus` и `game/symbols` обслуживает типизированный кодек. В движке хранятся значения передачи предметов, пять сохраняемых бросков и динамические целые `DIR_*`. Прежние символы ссылаются на те же значения. Проверка `SaveArchive` подтвердила порядок и ID 201 динамической переменной при записи с шаблоном NPC и загрузке в новую сессию.
- `StoryGraphRuntime` читает готовый граф и исполняет его через типизированный интерфейс без объектов VM. Сервер читает подготовленный граф из проверенной базы без исполняемых программ. Проекция `program-symbols` воспроизводит все поля и порядок 74 648 символов и содержит 0 байт инструкций. Тестовый профиль не обновляет указатель активной базы.
- Диспетчер и обработчик ошибок вынесены в отдельный объект линковки. Сборка с `OPENGOTHIC_LEGACY_DAEDALUS=OFF` использует состояние символов, нативные обработчики и готовые данные. Проверка линковки двух Linux-бинарников `a5a3c16fe` нашла 0 архивов Daedalus, 0 объектов VM и 0 символов диспетчера. Офлайн-конвертер той же сборки прошёл `--self-test`.

В первом точном снимке `5c2548aaa` свежий импорт Ryzen занял 8 мин 53 с. SHA-256 каталога графов совпал с независимой локальной сверкой. Полный `gothic-placed-items-contract` прошёл за 8 мин 53 с. Диалог Лареса выполнил подготовленную передачу орнамента без исполнения инструкций и восстановил параметры передачи после обычной загрузки. Журналы находятся на общем хранилище в `gothic-ai/native-game-runtime/`.

На том же снимке `gothic-basecontent-contract` прошёл за 3 мин 00 с, `gothic-npc-day-contract` выполнил 89 проверок. `hero-script-probe` завершился за 11 с с включённым строгим аудитом и прошедшими игровыми проверками карты, лечения и обмена с Халвором. Прогон содержал 6,034 с игрового времени. Установленный каталог содержит `MENU_MAIN`, всего 14 экранов и 273 элемента, а также проверенные разделы тактик, камеры, звука, музыки, частиц и визуальных эффектов.

На `a5a3c16fe` второй свежий импорт, включая ролики, завершился за 11 мин 21 с. В основной базе с отпечатком `309f56cad534329f…` осталось 0 исполняемых записей и 1 файл индекса `programs/programs.json`. Нативный `gothic-placed-items-contract` за 12,7 с проверил орнамент и сохранённые переменные Лареса, 2 331 размещённый объект и восстановление точной позы предмета с `zenId=2839`. Оконный `programs` прошёл 21 из 21. Обычный лаунчер открыл видимое `MENU_MAIN` и передал игре нативную базу, выбранную конвертером.

Сборка macOS `7a88a4ade` прошла обе проверки линковки. Контрольная сборка Linux с `OPENGOTHIC_LEGACY_DAEDALUS=ON` содержит диспетчер в обоих бинарниках. Платформенный «остров» прошёл маршрут под `strace`, четыре перехода между чанками и 1 486 проверок путей без обращений к игровым ресурсам.

Первый `p18b-base` на `a5a3c16fe` прошёл Хоринис, Яркендар и Долину Рудников. При входе в Ирдората строгий аудит остановил `B_CHECKLOG`: отложенная постановка NPC отключала нативный журнал. `load_rewind` поднял сейв из октября, записал новый слот и загрузил его. При проверке уведомления о смерти мост вызвал `B_GETCURRENTABSOLUTIONLEVEL` через общий старый путь. В сборке без диспетчера проверка журнала теперь доступна внутри смены главы, а мост заранее выбирает действующий нативный обработчик. Повтор этих двух оконных сценариев требует согласования бюджета.

## Приёмка

Два импорта по 15 минут, два контракта предметов по 12 минут, контракты базы и суток по 4 минуты. Один короткий безоконный сценарий героя до минуты и одни игровые сутки на seed 73106 до 20 минут с проверкой против архивного эталона. Оконные проверки: `programs`, `load_rewind`, `p18b-base` по 4 минуты и обычный старт меню до 2 минут. Сборка и ожидание очереди считаются отдельно.

Результат принимается по двум независимым проверкам. Карты линковки показывают отсутствие объектов VM, а точные штатные бинарники загружаются с валидной базой без программ, проходят сюжетные проверки, смену миров и старое и новое сохранения.
