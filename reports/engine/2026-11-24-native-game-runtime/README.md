# Gothic II без Daedalus в штатной игре

Цель — сборки `Gothic2Notr` и `gothic-body-runner` без интерпретатора для проверенной «Ночи Ворона». Старые сохранения этой программы читаются штатной сборкой. `content-convert` и отдельная сборка совместимости продолжают работать с исходными DAT.

## Перепись входов

Исходное дерево — `733c85bfc`. Суточная проверка Хориниса, холодная цепочка действий героя и оконная проверка меню и загрузки уже давали ноль инструкций на соответствующих сценариях. Перепись ниже учитывает также чтение инструкций без их исполнения и использование VM как хранилища.

## Порядок работ

1. Перепись, строгий наблюдатель, записи без обращений к упакованному `MENU.DAT`.
2. Типизированное состояние и старый формат сохранения. Первый сквозной граф — Ларес, `DIA_ADDON_LARES_PATCH_INFO` → `B_GIVEINVITEMS`. Сравнение с исходной VM включает орнамент, уведомления и три сохраняемых значения разных типов.
3. Остальные точки входа, готовые программы и данные глав, единый исполнитель для штатного сюжета и ИИ-моста.
4. Два игровых бинарника без линковки VM и штатная база без записей исполняемых программ. Лаунчер переключается после проверки обоих артефактов. Прежний комплект остаётся способом отката.

## Промежуточный результат

- Штатное меню выбирает каталог по метаданным. Конвертер готовит 11 423 программы StoryGraph, 4 139 определений диалогов и 37 привязок реплик по умолчанию к 147 темам. Сервер читает готовый граф из проверенного манифеста базы.
- В импорт вынесены размещения глав Хориниса, Долины Рудников и Яркендара, три начальные группы Ирдората, региональные помещения, правила 50 торговцев, 123 выдачи трофеев и 206 обращений к журналу. Для отсутствующих записей старых баз действует совместимость.
- Формат `game/daedalus` и `game/symbols` обслуживает типизированный кодек. В движке хранятся значения передачи предметов и пять сохраняемых бросков. Для исходных чисел и строк прежние символы ссылаются на те же значения.
- `StoryGraphRuntime` читает готовый граф и исполняет его через типизированный интерфейс без объектов VM. Из отдельно проверенной базы без байткода читается серверный граф. Оба игровых бинарника пока подключают диспетчер через `GameScript` и слой совместимости. Тестовый профиль базы отклоняется до обновления указателя активной базы.

В первом точном снимке `5c2548aaa` свежий импорт Ryzen занял 8 мин 53 с. SHA-256 каталога графов совпал с независимой локальной сверкой. Журналы находятся на общем хранилище в `gothic-ai/native-game-runtime/`.

## Приёмка

Два импорта по 15 минут, два контракта предметов по 12 минут, контракты базы и суток по 4 минуты. Один короткий безоконный сценарий героя до минуты и одни игровые сутки на seed 73106 до 20 минут с проверкой против архивного эталона. Оконные проверки: `programs`, `load_rewind`, `p18b-base` по 4 минуты и обычный старт меню до 2 минут. Сборка и ожидание очереди считаются отдельно.

Результат принимается по двум независимым проверкам. Карты линковки показывают отсутствие объектов VM, а точные штатные бинарники загружаются с валидной базой без программ, проходят сюжетные проверки, смену миров и старое и новое сохранения.
