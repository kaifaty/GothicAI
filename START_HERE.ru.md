# Gothic AI на Windows

**Предварительная сборка.** Готовый архив собран на GitHub из этого репозитория и прошёл там автоматические проверки. Компилятор и Visual Studio не нужны. Игра, графика, микрофон и голоса на настоящем компьютере ещё не проверялись: если что-то не работает, смотрите раздел «Если что-то не так».

## Что нужно

- Windows 10 или 11, 64 бита.
- Русская Gothic II Gold (с «Ночью Ворона»), купленная и установленная через Steam.
- Подписка ChatGPT и ключ API Inworld для голосов NPC.
- Интернет: при первой настройке скачиваются Python и библиотеки, в игре — ответы и голоса NPC.
- Микрофон. В «Параметры → Конфиденциальность → Микрофон» должно быть включено «Разрешить классическим приложениям доступ к микрофону».

## Первый раз

1. Скачайте из Releases архив `GothicAI-windows-x64-….zip`. Правый клик по нему → «Свойства» → отметьте «Разблокировать», если такая строка есть. Распакуйте архив целиком в короткую папку, например `C:\GothicAI`.
2. Если в Gothic II стоят моды (лишние архивы `.vdf` в папке `Data`), откройте командную строку в папке Gothic AI и выполните `Prepare-GothicAI-Game.cmd "полный путь к Gothic II"`. Он сделает отдельную папку только с оригинальными архивами через ссылки, ничего не копируя; игра и моды остаются как были, Gothic AI дальше берёт эту папку.
3. Запустите `Setup-GothicAI.cmd`. Он найдёт игру в Steam или попросит выбрать её папку. Потом попросит вставить ключ Inworld (символы при вводе не видны) и откроет браузер для входа в ChatGPT. Первая настройка скачивает несколько сотен мегабайт.
4. Когда появится «Готово», окно можно закрыть.

Отключать защитник Windows или менять политики не нужно.

## Игра

- Запускайте `Start-GothicAI.cmd`. Чёрное окно команд не закрывайте, пока играете: в нём работают ИИ-сервисы. Закроете игру — всё остановится само.
- Чтобы заговорить с NPC, удерживайте **T** и говорите, потом отпустите.
- Первый запуск дольше обычного: до старта игры Gothic AI несколько минут готовит её данные и ролики из файлов Gothic II, прогресс виден в чёрном окне. Готовые данные занимают несколько гигабайт в `%LOCALAPPDATA%\gothic-ai\base`, следующие запуски берут их сразу.
- После настройки браузер и Codex для игры не нужны.

## Если что-то не так

- Игра пишет, что нет `MSVCP140.dll` или `VCRUNTIME140.dll`: установите Microsoft Visual C++ Redistributable x64 с сайта Microsoft: https://aka.ms/vs/17/release/vc_redist.x64.exe
- Ошибка про `vulkan-1.dll` или чёрный экран: обновите драйвер видеокарты с сайта её производителя.
- NPC не слышат вас: запустите `Check-Microphone.cmd`. Он скажет, запрещён ли доступ к микрофону, выключен ли микрофон в Windows или его не видно, и что сделать. Звук он не записывает и настройки не меняет.
- Чтобы сменить ключ Inworld, откройте командную строку в папке Gothic AI и выполните `Setup-GothicAI.cmd -ChangeKey`.
- Для всего остального запустите `Diagnostics-GothicAI.cmd` и покажите Codex файл, который он назовёт. Ключей и токенов в нём нет.
